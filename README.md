# About Me:
Hi, I'm **Vext**. I've been scripting Roblox for about 3.5 years, mostly freelancing and building game systems. Right now I'm working on **Blight vs Harvest**, a team game with modules, remotes, and a lot of moving parts. I've also worked on unreleased games with a well-known developer, which was a fun one.<br>These days I'm learning **Rust**, mostly because I want to see how another language handles the same problems I solve in Luau. I'm open to collaborating with other devs on games, and I'm available for scripting commissions, 15+ hours a week.
